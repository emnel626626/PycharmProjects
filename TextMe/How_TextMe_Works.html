How TextMe Works

A daily multiple-choice quiz by text message, generated from your study PDFs. Numbers on the arrows match the steps on page 2.

Step by step

1 · Build the questions (once)

  1. The app reads the text and images from the study PDFs.
  2. It sends the text to Claude, which writes 10 multiple-choice questions with friendly explanations and notes which page each came from.
  3. For each question with an image on its page, Claude checks whether the picture actually shows what the question is about and does not give the answer away. Only pictures that pass are used.
  4. Everything is saved in questions_cache.json. Delete that file to get a fresh set of questions.

2 · Daily send (9:00 every day)

  1. The app reads recipients.txt and skips anyone who has texted STOP.
  2. For each person it picks their next question (tracked in progress.json).
  3. It asks Twilio to send it, with a picture if that question has one.
  4. Twilio delivers it through the approved A2P 10DLC campaign.

3 · Reply and feedback

  1. The person texts back A, B, C or D.
  2. Twilio forwards the text to the ngrok web address, which passes it to the app's /webhook.
  3. The app checks the answer and replies with CORRECT or INCORRECT plus the explanation.
  4. START or QUIZ gets an extra question right away. HELP gets info. STOP unsubscribes.

4 · Log and report

  1. Every opt-in, question sent, answer (right or wrong) and opt-out is added to events.jsonl.
  2. Open http://localhost:5000/report to see each person's results, the hardest questions, and recent activity.
  3. The report has a CSV download for Excel.
  4. If the app restarts, unanswered questions are rebuilt from this log, so late replies still count.

Things to know

  • This computer must stay on with both the app and ngrok running (start_textme.bat starts both). If it's off at 9:00, nobody gets that day's question.
  • Twilio needs funds. When the balance ran out, the account was suspended and nothing could be sent. Auto-recharge is on.
  • Only text people who agreed. The campaign rules require consent from everyone in recipients.txt.
  • The report shows phone numbers, so it only opens on this computer unless a REPORT_KEY is set in .env.
  • Send a question now: in PowerShell, Invoke-WebRequest -Method POST http://localhost:5000/send-now -UseBasicParsing
